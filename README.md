A [Copier](https://copier.readthedocs.io/) template for Rust library projects.

## Quickstart

1. Install the latest Copier via command:

    ```sh
    pip install --upgrade copier copier-template-extensions
    ```

2. Use command `copier` to generate a new project:

    ```sh
    copier copy gh:garrett-he/copier-rust /path/to/destination
    ```
